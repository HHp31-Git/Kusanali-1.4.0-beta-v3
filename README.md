# 吉祥草之音

For the Lesser Lord Kusanali. All right reserved[1,6](@ref)

## 🚀 快速开始

### 前提条件

本mod适用版本：
-   Java 21
-   Minecraft 1.20.1
-   fabric-loader 0.14.21

注意事项：
-   需要前置：geckolib(建议版本:4.7.4)

### 安装与运行

这非常简单：将jar文件放入.minecraft目录下的mods文件夹中，
