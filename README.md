# 吉祥草之音

## 🚀 快速开始

### 前提条件

本mod适用版本：
-   Java 21
-   Minecraft 1.20.1
-   fabric-loader 0.14.21

- 特殊武器"千夜浮梦"
- 特殊维度"梦境之地"
- 多个特殊事件和能力系统
