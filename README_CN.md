# 🌸吉祥草之音

For the Lesser Lord Kusanali. 
All right reserved[1,6](@ref)

## 🔧 技术信息

本mod适用版本：

-   Minecraft 1.20.1
-   fabric-loader >=0.14.21
- 需要Fabric API

## ✨ 模组简介

- 本模组围绕 [元素反应系统] 和 专属武器 [千夜浮梦] 展开，为 Minecraft 带来全新的战斗机制、世界生成内容和收集要素。
- 
## 🌟 简介

-🎮 核心玩法 : 元素反应系统
-模组引入了 7 种元素状态效果，当实体同时携带两种元素时，会触发对应的元素反应：

反应类型	   参与元素	        效果
扩散	       风 + (火/冰/水)	将元素扩散到周围 1.5 格内的实体
蒸发	       火 + 冰	        纯伤害
冻结	       冰 + 水	        生成 [冻结] 效果，阻止攻击和移动
碎冰	       冻结 + 物理伤害	额外 4 点伤害，解除冻结
融化	       火 + 冰	        纯伤害
超载        雷 + 火	        爆炸 + 击退
超导  	   雷 + 冰	        伤害 + 附加 [超导] 减益效果

-🗡️ 专属武器：[千夜浮梦]
-普通攻击：

操作	               效果
左键	               连续释放 4 个魔法方阵，每个造成 7 点范围伤害（燃烧目标 +1）+ 草元素附着
右键蓄力（0.7 秒）	   180° 扇形重击，造成 10 点范围伤害（燃烧目标 +1）+ 草元素附着

-技能系统：

默认按键	  技能名称	冷却	         效果
R	      心景幻成	30 秒	     30 格半径内所有敌对生物持续受到魔法伤害 + 草元素附着
G	      所识遍记	5 秒 / 3 秒   扇形锁定攻击 + 采集周围植物 + 附加蕴种印效果 + 草元素附着

-被动效果：

攻击处于 [燃烧] 状态的敌人时，伤害额外 +1 ，配合元素反应系统可打出更高伤害

-🪖 特殊装备:
装备	          效果
虚空终端	      佩戴后获得无限夜视效果
兰那罗花冠	  佩戴后获得无限幸运效果

-🌍 世界生成：
-新植物:

名称	            生成位置	    说明
枣椰树         	恶地群系	    新的树木种类，可砍伐获取木材和树苗
须弥蔷薇        	主世界全境	装饰性花卉，可用于合成或装饰

-新战利品:

物品	            获取方式	            概率
《我从未遗忘》唱片	丛林神庙宝箱、合成	    20%
兰那罗之花	    丛林神庙宝箱、末地城	30%
